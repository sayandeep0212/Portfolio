# Contributing to Sayandeep Pradhan's Portfolio

Thank you for your interest in contributing!

## Code of Conduct
Please maintain a respectful and constructive atmosphere.

## Development Workflow
1. Fork the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/your-feature-name
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Ensure all tests and type checks pass:
   ```bash
   npx tsc --noEmit
   npm run build
   ```
4. Commit your changes with clear messages and open a Pull Request.
